# Bajaj Inventory Management System

A database-driven web application for managing
inventory, purchases, sales and customers
at a Bajaj spare parts shop.

## Technologies

### Frontend
- React
- Vite
- Axios
- React Router

### Backend
- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security
- JWT Authentication

### Database
- PostgreSQL
- Flyway

## Project Structure

- frontend: React application
- backend: Spring Boot application
- database: Database documentation
- docs: Project documentation
